Credit Risk & Loan Analysis Dashboard

Project Overview

This project analyzes customer loan and credit data to identify borrowing patterns, credit risk factors, and customer financial behavior. The project demonstrates the complete data analytics workflow using Python, SQL, and Power BI.

Tools Used

- Python (Pandas, NumPy, Matplotlib)
- SQL
- Power BI
- Jupyter Notebook

Project Workflow

1. Data Cleaning (Python)

- Handled missing values using median and mode.
- Removed unnecessary identifier columns.
- Corrected data quality issues.
- Standardized column names and data types.

2. Feature Engineering

#Created additional analytical columns including:

- Credit Category
- Debt-to-Income Ratio
- Risk Segmentation

3. Exploratory Data Analysis

#Performed analysis on:

- Loan purposes
- Credit score distribution
- Home ownership patterns
- Customer income trends
- Debt characteristics

4. SQL Analysis

#Key SQL analyses included:

- Average loan amount by purpose
- Credit score comparison across customer groups
- Credit category distribution
- Customer risk analysis
- Window function-based ranking

5. Power BI Dashboard

#Dashboard KPIs:

- Total Customers
- Total Loan Amount
- Average Loan Amount
- Average Credit Score
- Average Annual Income

#Interactive Filters:

- Purpose
- Credit Category
- Loan Term

#Key Insights

- Good credit customers represented the largest customer segment.
- Loan amounts varied significantly across loan purposes.
- Home ownership status influenced customer credit profiles.
- Higher credit categories generally demonstrated stronger financial stability.
